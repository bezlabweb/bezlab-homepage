# 자료실에 자료 추가하는 방법

홈페이지 **자료실** 화면(www.bezlab.co.kr/resources/)은 이 폴더의 `list.json` 파일 한 곳에 적힌 목록을 그대로 보여줍니다.
자료 하나를 올리려면 **① 파일 올리기 → ② 목록에 한 줄 추가하기** 두 단계만 하면 됩니다. 저장하고 1~2분 뒤 홈페이지에 반영됩니다.

---

## ① 파일 올리기

1. GitHub 저장소에서 `resources` → `files` 폴더로 들어갑니다.
2. 오른쪽 위 **Add file → Upload files**를 누릅니다.
3. 올릴 파일(PDF, 이미지 등)을 끌어다 놓습니다.
   - 파일 이름은 **영문 소문자·숫자·하이픈(-)** 으로 해 주세요. 예) `greenremodel-guide-2026.pdf`
   - 한글이나 띄어쓰기가 들어간 이름은 주소가 깨질 수 있습니다.
4. 아래 **Commit changes**를 누릅니다.

## ② 목록에 한 줄 추가하기

1. `resources` 폴더의 `list.json`을 열고 연필 모양(✏️ Edit) 버튼을 누릅니다.
2. 맨 앞 `[` 바로 아래에 아래 덩어리를 복사해 붙이고 내용을 바꿉니다.

```json
  {
    "title": "자료 제목",
    "category": "기술자료",
    "date": "2026-12-01",
    "summary": "목록에 제목 아래 작게 보일 한두 줄 설명",
    "file": "files/올린-파일-이름.pdf"
  },
```

3. **Commit changes**를 누릅니다.

### 각 칸의 뜻

| 칸 | 뜻 | 예시 |
| --- | --- | --- |
| `title` | 목록에 보이는 제목 | `"히트펌프(Heat Pump)의 원리"` |
| `category` | 분류 탭 이름. 새 이름을 쓰면 탭이 자동으로 생깁니다 | `"기술자료"`, `"지원사업 안내"`, `"정책·법령"` |
| `date` | 등록일. 최신 날짜가 목록 맨 위로 옵니다 | `"2026-12-01"` |
| `summary` | 제목 아래 작은 설명 (없어도 됨) | |
| `file` | ①에서 올린 파일 위치. 앞에 `files/`를 붙입니다 | `"files/guide.pdf"` |
| `page` | 따로 만든 설명 페이지가 있을 때만 씁니다 (없으면 줄 자체를 빼세요) | `"heatpump.html"` |

`page`가 없으면 **보기** 버튼은 파일 자체를 열어 보여줍니다.

### 자주 하는 실수

- 덩어리와 덩어리 사이에는 **쉼표(,)** 가 있어야 하고, **맨 마지막 덩어리 뒤에는 쉼표가 없어야** 합니다.
- 따옴표는 반드시 키보드의 곧은 따옴표 `"`를 씁니다. (“ ” 같은 둥근 따옴표는 안 됩니다)
- 저장 후 자료실에 "자료 목록을 불러오지 못했습니다"가 보이면 대부분 쉼표나 따옴표 문제입니다. 방금 고친 부분을 다시 확인하세요.

## 자료 내리기

`list.json`에서 해당 덩어리 `{ ... },`를 지우면 목록에서 사라집니다. 파일 자체도 지우려면 `files` 폴더에서 파일을 열고 휴지통(🗑) 버튼을 누르세요.
